# HardwareConfiguration

Details about the computational hardware used to run a model simulation.

| Field | Required | Many | Type | Description |
|---|---|---|---|---|
| machine | no | no | string | Name of the machine or cluster (e.g., 'Perlmutter'). |
| operating_system | no | no | string | Operating system used (e.g., 'Linux'). |
| cpu_gpu_details | no | no | string | Details about CPU/GPU hardware or link to specifications. |
| memory | no | no | string | Memory available (e.g., '512 GB DDR4'). |
| storage | no | no | string | Storage available (e.g., '44 PB'). |
| parallelization | no | no | string | Parallelization details (e.g., '3 nodes, 108 ntasks per node'). |
