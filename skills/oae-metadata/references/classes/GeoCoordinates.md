# GeoCoordinates

A geographic coordinate in decimal degrees.

| Field | Required | Many | Type | Description |
|---|---|---|---|---|
| latitude | yes | no | float | Latitude in decimal degrees of a location. For example 37.42242 (WGS 84). |
| longitude | yes | no | float | Longitude in decimal degrees of a location. For example -122.08585 (WGS 84). |
