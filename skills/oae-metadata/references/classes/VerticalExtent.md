# VerticalExtent

The vertical extent of a place or structure in meters.

| Field | Required | Many | Type | Description |
|---|---|---|---|---|
| min_depth_in_m | no | no | float | Minimum depth of observation in meters. Use negative numbers for depths below sea level. |
| max_depth_in_m | no | no | float | Maximum depth of observation in meters. Use negative numbers for depths below sea level. |
| min_height_in_m | no | no | float | Minimum height of observation (in meters) for above ground aerial coverage. |
| max_height_in_m | no | no | float | Maximum height of observation (in meters) for above ground aerial coverage. |
