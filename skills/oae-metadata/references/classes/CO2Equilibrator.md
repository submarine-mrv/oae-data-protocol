# CO2Equilibrator

Equilibrator used for continuous CO2 measurement.

| Field | Required | Many | Type | Description |
|---|---|---|---|---|
| equilibrator_type | no | no | string | Type of the equilibrator for the CO2 measurement. |
| volume | no | no | float | The total volume (in liters) of the CO2 equilibrator. |
| vented | no | no | boolean | Is the equilibrator vented or not? |
| water_flow_rate | no | no | float | Flow rate (in L/min) of the flow through seawater. |
| headspace_gas_flow_rate | no | no | float | Flow rate (in L/min) of the gas from the equilibrator to the CO2 analyzer. |
