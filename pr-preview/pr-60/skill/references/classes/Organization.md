# Organization

| Field | Required | Many | Type | Description |
|---|---|---|---|---|
| name | yes | no | string | Name of the organization |
| identifier | no | no | string | Organization identifier in the form of an ROR URL (e.g., https://ror.org/02mhbdp94). Please visit [https://ror.org](https://ror.org) to search for the organization and find the appropriate ROR URL. |
| country | no | no | string | The country in which the organization belongs. |
