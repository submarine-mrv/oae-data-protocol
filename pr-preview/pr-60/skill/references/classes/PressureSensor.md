# PressureSensor

Pressure sensor used in continuous CO2 measurements. Accuracy and precision are reported in hectopascals (hPa).

Parent: GenericSensor

| Field | Required | Many | Type | Description |
|---|---|---|---|---|
| location | no | no | string | Location of the sensor. |
| manufacturer | no | no | string | Manufacturer of the sensor. |
| model | no | no | string | Model number of the sensor. |
| serial_number | no | no | string | Serial number of the sensor. |
| accuracy | no | no | float | Accuracy of the pressure sensor in hectopascals (hPa). |
| precision | no | no | float | Precision of the pressure sensor in hectopascals (hPa). |
| calibration | no | no | string | Calibration information for the sensor. |
| comments | no | no | string | Additional comments about the sensor. |
