# SamplePreservation

Sample preservation information for DIC and TA measurements. Reference: OAPMetadata XSD variables.xsd - sample_preservation

| Field | Required | Many | Type | Description |
|---|---|---|---|---|
| preservative | yes | no | string | As described, e.g., Mercury Chloride. |
| volume | yes | no | string | The volume of preservative used. |
| correction_description | no | no | string | Description of how the preservative effect was corrected for. |
