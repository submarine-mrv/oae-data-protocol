# MarineAirMeasurement

Information about CO2 measurements in marine air.

| Field | Required | Many | Type | Description |
|---|---|---|---|---|
| measured | yes | no | boolean | Whether CO2 in marine air was measured. |
| measurement_interval | no | no | string | How often marine air CO2 is measured, e.g., 5 readings in a group every 5 hours. |
| location_and_height | no | no | string | Location and height of the marine air intake. |
| drying_method | no | no | string | Method used to dry the gas stream for marine air measurements. |
